## Project Workflow

### 1. Data Loading
- Imported the dataset into Python using Pandas.
- Inspected the dataset structure, columns, and data types.
- Reviewed the initial records to understand the data.

### 2. Exploratory Data Analysis (EDA)
- Analyzed descriptive statistics and data distributions.
- Identified trends, patterns, and relationships between variables.
- Explored missing values, duplicates, and potential outliers.
- Created visualizations to support initial findings.

### 3. Data Cleaning & Preprocessing
- Handled missing and inconsistent values.
- Removed duplicate records where appropriate.
- Corrected data types and standardized column values.
- Prepared the cleaned dataset for SQL analysis and visualization.

### 4. SQL Analysis
- Loaded the cleaned data into PostgreSQL, MySQL, or SQL Server.
- Wrote SQL queries to answer relevant business questions.
- Used filtering, aggregation, joins, subqueries, and window functions where appropriate.
- Analyzed key metrics, trends, and performance indicators.

### 5. Power BI Dashboard
- Connected Power BI to the cleaned dataset or SQL database.
- Created KPIs, charts, tables, and interactive filters.
- Designed a user-friendly dashboard to highlight important insights.
- Used slicers and drill-downs where relevant to support deeper analysis.

### 6. Report Creation
- Summarized the project objectives, methodology, and analysis.
- Documented key findings and business insights.
- Presented conclusions and recommendations based on the results.

### 7. Presentation Using Gamma
- Created a professional presentation using Gamma.
- Summarized the business problem, analytical approach, and key findings.
- Included dashboard visuals, major insights, and recommendations.
